## 📥 Импорт и экспорт данных

### Импорт (Excel / CSV)

1. Откройте нужный раздел и нажмите **«Импорт»**.
2. Загрузите `.xlsx` или `.csv` файл.
3. Сопоставьте колонки файла с полями БД.
4. Для связей (relations) система подбирает соответствия как по текстам/названиям, так и по ID.
5. При наличии ошибочных строк система автоматически сформирует и предложит скачать файл `Ошибки_импорта_<Раздел>.xlsx` с указанием причины по каждой строке.

### Экспорт

* **CSV**: Выгружает данные текущей таблицы с учетом фильтрации и поиска.
* **DOCX**: При экспорте ЖВК формируется официальный документ Word на основе шаблона `templates/inj_template.docx` с автоматической группировкой по объектам и расчетом начальной/конечной даты.

## 🔒 Управление правами доступа (RBAC)

Права доступа настраиваются индивидуально для каждого пользователя в поле `global_access` (JSON) со следующими параметрами по каждой коллекции:

* `create` — разрешение на создание записей.
* `update` — разрешение на редактирование.
* `delete` — разрешение на удаление.
* `import_export` — доступ к функциям импорта/экспорта.
* `view_all_items` — возможность видеть все записи (иначе действует фильтр по ответственным объектам/проектам).
* `view_all_columns` — доступ к конфиденциальным колонкам (например, цены договоров и служебные данные).

Администратор может настраивать права в удобном GUI интерфейсе карточки пользователя, а также экспортировать и импортировать матрицы прав в `.json`.

## 🚀 Быстрый запуск

Приложение не требует этапа сборки (`no build step`).

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/global-stroy.git
cd global-stroy

```

### 2. Подключение к бэкенду

Откройте файл `scripts/config.js` и укажите адрес вашего PocketBase-сервера:

```javascript
const pb = new PocketBase('https://your-pocketbase-domain.com');

```

### 3. Запуск приложения

Запустите статический веб-сервер в корневой папке проекта:

* **VS Code**: Используйте расширение `Live Server`.
* **Python**:
```bash
python3 -m http.server 8000

```


* **Nginx / Caddy / Apache**: Разместите файлы из репозитория в публичной папке веб-сервера.

## 🗄 Настройка PocketBase (Бэкенд)

Для полноценной работы создайте в PocketBase следующие коллекции согласно структуре из `scripts/config.js`:

1. `companies` — Компании (`name`, `inn`, `email`, `phone`)
2. `contacts` — Контакты (`last_name`, `first_name`, `patronymic`, `position`, `company`, `email`, `phone`)
3. `users` — Пользователи (`last_name`, `first_name`, `patronymic`, `position`, `company`, `role`, `global_access`)
4. `objects` — Объекты (`name`, `global_counterparty`, `contract`, `contract_price`)
5. `projects` — Проекты (`object`, `name`, `responsible_users`)
6. `groups` — Группы (`projects`, `name`)
7. `materials` — Материалы (`project`, `name`, `replacement`, `unit`, `quantity_spec`)
8. `supply` — Поставки / ЖВК (`supply_date`, `material`, `quantity`, `supplier`, `doc_data`, `inspection_result`, `is_lab_required`, `lab_result`, `author`)
9. `facts` — Расход / ЖРМ (`date`, `material`, `quantity`, `user`)
10. `doc_status_log` — ИТД (`project`, `status`, `contact`, `responsible_company`, `responsible_user`, `signed_by`, `comment`)
11. `general_work_log` — ОЖР (`date`, `project`, `condition`, `name`, `responsible`)

## 📥 Импорт и экспорт данных

### Импорт (Excel / CSV)

1. Откройте нужный раздел и нажмите **«Импорт»**.
2. Загрузите `.xlsx` или `.csv` файл.
3. Сопоставьте колонки файла с полями БД.
4. Для связей (relations) система подбирает соответствия как по текстам/названиям, так и по ID.
5. При наличии ошибочных строк система автоматически сформирует и предложит скачать файл `Ошибки_импорта_<Раздел>.xlsx` с указанием причины по каждой строке.

### Экспорт

* **CSV**: Выгружает данные текущей таблицы с учетом фильтрации и поиска.
* **DOCX**: При экспорте ЖВК формируется официальный документ Word на основе шаблона `templates/inj_template.docx` с автоматической группировкой по объектам и расчетом начальной/конечной даты.

## 🔒 Управление правами доступа (RBAC)

Права доступа настраиваются индивидуально для каждого пользователя в поле `global_access` (JSON) со следующими параметрами по каждой коллекции:

* `create` — разрешение на создание записей.
* `update` — разрешение на редактирование.
* `delete` — разрешение на удаление.
* `import_export` — доступ к функциям импорта/экспорта.
* `view_all_items` — возможность видеть все записи (иначе действует фильтр по ответственным объектам/проектам).
* `view_all_columns` — доступ к конфиденциальным колонкам (например, цены договоров и служебные данные).

Администратор может настраивать права в удобном GUI интерфейсе карточки пользователя, а также экспортировать и импортировать матрицы прав в `.json`.
